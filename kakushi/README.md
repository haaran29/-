# 写真かくし

写真の顔や名前など、見せたくないところを隠して保存するアプリです。

- 開くURL：https://haaran29.github.io/-/kakushi/
- 本体：`index.html`（このファイル1つで動きます）

## できること
1. 「写真を選ぶ」で写真を開く（ドラッグ＆ドロップや貼り付けでも開けます）
2. 写真のすぐ下のバーで、かくし方を選ぶ：ぼかし・モザイク・ぬりつぶし・スタンプ。形（丸・四角）、強さ、色、スタンプの種類もバーで選べます（絵文字のほか、サングラス・アイマスク・マスクのスタンプもあります）
3. 隠したいところをタップするか、なぞって囲む（かくし方やスタンプを選んだあとの1回だけ置けます。ただ触っただけでは何も置かれず、写真の上でもスクロールできます）
4. 隠した場所はドラッグで動かせて、角をつまむと大きさを変えられます。タップして選ぶと、写真のすぐ下のバーで消したり、ほかのかくし方やスタンプに変えたりできます（バーは「バーを隠す」でしまえます）
5. 「隠した写真を保存」で保存する

写真はその端末の中だけで処理され、どこにも送られません。保存した画像には撮影場所などの情報（Exif）は残りません。
