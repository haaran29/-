# 付箋TODO（スマホ版）

スマホで使える付箋TODOです。パソコン版（`sticky-notes/`）と同じように、やることを書いてチェック ✅ を入れられます。

- 開くURL：https://haaran29.github.io/-/fusen/
- メモはそのスマホの中だけに保存されます（パソコン版とはつながっていません）
- 一度開けば、電波がなくても使えます

## ホーム画面に追加する
- iPhone（Safari）：下の共有ボタン → 「ホーム画面に追加」
- Android（Chrome）：右上の︙ → 「ホーム画面に追加」（または「アプリをインストール」）

iPhone はホーム画面に追加しておくと、しばらく開かなくてもメモが消されにくくなります。
