# 新聞切り抜き台紙メーカー

新聞記事の写真を撮って、日付と新聞名を入れたA4の台紙をPDFまたはJPGで作るアプリです。

- 本体：`index.html`（このファイル1つで動きます）
- 公開URL（GitHub Pages）：https://haaran29.github.io/-/
- 元になったもの：Claude のチャットで作ったアーティファクト

## できること
1. 日付を選ぶ（曜日は自動で入ります）
2. 新聞名を入れる
3. 記事の写真を撮る・選ぶ（切り取りと回転ができます）
4. メモを書く（書かなくても大丈夫です）
5. PDF（印刷用）またはJPGで保存する

綴じしろとして、上に3cm、左に2.5cmの余白があります。

## 印刷について
- ふつうのウェブサイト（GitHub Pages など）として開くと、スマホでも「印刷する」から直接印刷画面が出ます。
- Claude の画面の中で開くと、スマホでは印刷画面を出せないため、台紙の画像を長押しして印刷する案内になります。
