# 付箋TODO

パソコンの画面にいつも出ている付箋メモです。やることを書いて、終わったらチェック ✅ を入れられます。

## できること
- 付箋はほかのウィンドウより**いつも手前**に出ています（📌 で切り替え）
- やることを書いて Enter で追加、□ を押すと ✅ と取り消し線
- 「完了したものを消す」で終わったものをまとめて消せます
- 付箋は ＋ でいくつでも増やせます。色は 🎨 で6色から選べます
- 上の帯をつかむと動かせて、ふちを引っぱると大きさを変えられます
- 書いた内容・場所・大きさは自動で保存され、次に開いたときもそのまま出ます
- タスクトレイ（画面右下）のアイコンを右クリックすると
  「新しい付箋」「すべての付箋を表示」「パソコン起動時に開く」「終了」が選べます

## 使い方（ちょっとした操作）
| 操作 | すること |
| --- | --- |
| やることを追加 | 下の「やることを追加」に書いて Enter |
| 書き直す | 文字をクリックしてそのまま直す |
| 1つ消す | 行にマウスをのせると出る ✕ |
| 付箋ごと消す | 上の帯の ✕ |

## ダウンロード（Windows／Mac）
1. GitHub のこのリポジトリの **Actions** タブを開く
2. 「付箋アプリをつくる」の一番上（緑のチェックがついたもの）を開く
3. 下の **Artifacts** から
   - Windows：`FusenTodo-win` → 中の `FusenTodo-Setup-….exe`（インストール版）か
     `FusenTodo-Portable-….exe`（インストールせずにそのまま動く版）
   - Mac：`FusenTodo-mac` → 中の `.dmg`

※ 署名をしていないアプリなので、初めて開くときに注意の画面が出ます。
- Windows：「WindowsによってPCが保護されました」→「詳細情報」→「実行」
- Mac：アプリを右クリック →「開く」→「開く」

## 自分のパソコンで動かす（開発用）
Node.js が入っていれば：
```
cd sticky-notes
npm install
npm start
```
